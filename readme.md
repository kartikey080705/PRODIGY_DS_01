# PRODIGY_DS_01

## Task 01: Data Visualization

This project visualizes the distribution of a continuous variable (Age) and a categorical variable (Gender) using a sample dataset created for demonstration purposes.

### Tools Used:
- Python
- Pandas
- Matplotlib

### Visualizations:
- Histogram for Age distribution
- Bar chart for Gender distribution

### Insights:
- Majority of individuals are between 20 and 40 years of age.
- Gender distribution is nearly balanced.
